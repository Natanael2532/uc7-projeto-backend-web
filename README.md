# Plataforma de Cursos

Projeto desenvolvido na UC7.

## Funcionalidades

- Cadastro de usuários
- Login
- Consulta de cursos

## Tecnologias

- Python
- Django
- Git
- GitHub

Permitir que os usuários realizem seu cadastro de usuários, depois permite acessar o sistema via login e realizar consulta de cursos na plataforma

✅ Público-alvo:
Estudantes , professores, diretores, coordenadores, supervisores e responsáveis pelos alunos
